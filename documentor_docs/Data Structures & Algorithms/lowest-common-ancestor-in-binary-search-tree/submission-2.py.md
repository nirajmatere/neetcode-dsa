# Technical Documentation: Lowest Common Ancestor in a Binary Search Tree

## Overview

This file provides an implementation for finding the **Lowest Common Ancestor (LCA)** of two given nodes, `p` and `q`, within a Binary Search Tree (BST). The algorithm utilizes the structural property of BSTs (left subtrees contain smaller values, right subtrees contain larger values) to recursively navigate through the tree.

---

## Class and Method Definitions

### `TreeNode` (Commented Interface)
Represented in comments at the top of the file:
```python
class TreeNode:

    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```
*   `val`: Integer value stored in the node.
*   `left`: Pointer to the left child node (`TreeNode` or `None`).
*   `right`: Pointer to the right child node (`TreeNode` or `None`).

---

### `Solution` Class

#### `lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode`

Finds and returns the lowest node in the BST that has both `p` and `q` as descendants (where a node can be a descendant of itself).

##### Parameters:
*   `root` (`TreeNode`): The root node of the current BST (or subtree).
*   `p` (`TreeNode`): The first target node.
*   `q` (`TreeNode`): The second target node.

##### Return Value:
*   `TreeNode`: The node that represents the lowest common ancestor of `p` and `q`.

---

## Detailed Logic & Execution Flow

The function operates through the following sequential steps:

### 1. Target Ordering (Normalization)
```python
if p.val > q.val:
    temp = q
    q = p
    p = temp
```
*   Compares the integer values of `p` and `q`.
*   If `p.val` is greater than `q.val`, the references are swapped using variable `temp`.
*   **Result:** Ensures that `p.val` is always less than or equal to `q.val` for subsequent comparisons.

---

### 2. Equality Checks
```python
if root and root.val == p:
    return p
if root and root.val == q:
    return q
```
*   Checks if the current `root` is non-null and evaluates equality against target nodes `p` and `q`.

---

### 3. Divergence / Split Check
```python
if root.val > p.val and root.val < q.val:
    return root
```
*   If the current `root.val` lies strictly between `p.val` and `q.val` (`p.val < root.val < q.val`), `root` is the split point where `p` lies in the left subtree and `q` lies in the right subtree.
*   Returns `root` as the lowest common ancestor.

---

### 4. Right Subtree Traversal
```python
if root.val < p.val and root.val < q.val:
    return self.lowestCommonAncestor(root.right, p, q)
```
*   If `root.val` is strictly smaller than both `p.val` and `q.val`, both target nodes must reside in the right subtree.
*   Recursively calls `lowestCommonAncestor` passing `root.right`.

---

### 5. Left Subtree Traversal
```python
if root.val > p.val and root.val > q.val:
    return self.lowestCommonAncestor(root.left, p, q)
```
*   If `root.val` is strictly greater than both `p.val` and `q.val`, both target nodes must reside in the left subtree.
*   Recursively calls `lowestCommonAncestor` passing `root.left`.

---

### 6. Default Fallback
```python
return root
```
*   If none of the explicit recursive step conditions are met, the function returns `root`.

---

## Complexity Analysis

*   **Time Complexity:** $\mathcal{O}(H)$, where $H$ is the height of the Binary Search Tree.
    *   In a balanced BST, the height is $\mathcal{O}(\log N)$, where $N$ is the number of nodes.
    *   In a skewed BST, the height can be $\mathcal{O}(N)$.
*   **Space Complexity:** $\mathcal{O}(H)$ due to the call stack overhead generated by the recursive calls.
