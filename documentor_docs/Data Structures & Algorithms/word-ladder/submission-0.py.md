# Technical Documentation: Word Ladder Solver (`submission-0.py`)

**File Path:** `Data Structures & Algorithms/word-ladder/submission-0.py`

## Overview

The `submission-0.py` file provides a Python solution to the **Word Ladder** problem via the `Solution` class. The objective is to find the length of the shortest transformation sequence from a starting word (`beginWord`) to a target word (`endWord`), where each intermediate step changes exactly one character, and every intermediate word must exist within a given list of valid words (`wordList`).

The implementation uses an **intermediate pattern graph representation** combined with **Breadth-First Search (BFS)** to locate the shortest path efficiently.

---

## Class & Method Signatures

### `class Solution`

Contains the primary algorithm for solving the word ladder sequence length.

#### `ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int`

Calculates the shortest transformation sequence length from `beginWord` to `endWord`.

*   **Parameters:**
    *   `beginWord` (`str`): The starting word of the transformation.
    *   `endWord` (`str`): The goal target word.
    *   `wordList` (`List[str]`): A list of valid intermediate words.
*   **Returns:**
    *   `int`: The total number of words in the shortest transformation sequence (including `beginWord` and `endWord`). Returns `0` if `endWord` is not in `wordList` or no valid sequence exists.

## Key Components & Logic Breakdown

The code operates in three main phases:

### 1. Early Termination Check
```python
if endWord not in wordList:
    return 0
```
Before building graphs or starting the search, the method checks if `endWord` is present in `wordList`. If `endWord` is missing, a transformation is impossible, and the function immediately returns `0`.

---

### 2. Intermediate Pattern Graph Construction
```python
adj = defaultdict(list)
wordList.append(beginWord)
for word in wordList:
    for i in range(len(word)):
        pattern = word[:i] + '*' + word[i+1:]
        adj[pattern].append(word) 
```

Rather than comparing every pair of words to determine if they differ by one letter ($O(N^2 \cdot L)$), the code builds an adjacency list mapping intermediate wildcard patterns to words.

*   `beginWord` is appended to `wordList` to ensure it is included in the graph layout.
*   For each word of length $L$, $L$ generic patterns are generated by replacing the character at index `i` with `'*'`.
    *   *Example:* For `"hit"`, generated patterns are `"*it"`, `"h*t"`, and `"hi*"`.
*   `adj[pattern]` stores all words that match that specific single-wildcard pattern. Two words sharing a common pattern differ by exactly one character and are adjacent.

---

### 3. Level-by-Level Breadth-First Search (BFS)
```python
q = deque()
visited = set()
count = 1
q.append(beginWord)
visited.add(beginWord)

while q:
    for i in range(len(q)):
        word = q.popleft()
        if word == endWord:
            return count
        for i in range(len(word)):
            pattern = word[:i] + '*' + word[i+1:]
            for nei in adj[pattern]:
                if nei not in visited:
                    q.append(nei)
                    visited.add(nei)
    
    count += 1

return 0
```

Because BFS explores nodes layer-by-layer, the first time `endWord` is encountered guarantees the shortest path length.

1.  **Initialization:**
    *   `q`: A double-ended queue (`deque`) initialized with `beginWord`.
    *   `visited`: A set tracking explored words to prevent cycles and redundant visits, initialized with `beginWord`.
    *   `count`: Set to `1`, representing the step/word count of the current sequence.
2.  **Level Traversal Loop:**
    *   `for i in range(len(q))` snapshot processes all nodes at the current distance layer.
    *   Pop the front `word` from `q`.
    *   **Target Check:** If `word == endWord`, return `count`.
    *   **Neighbor Discovery:** Reconstruct the $L$ generic patterns for `word`. For each `pattern`, look up adjacent words (`nei`) in `adj[pattern]`.
    *   **Enqueuing:** Unvisited neighbors are added to both `q` and `visited`.
3.  **Increment Distance:**
    *   Once all words at the current level are processed, `count` is incremented by `1`.
4.  **Fallback Return:**
    *   If `q` becomes empty without reaching `endWord`, return `0`.

## Variable Reference Table

| Variable | Type | Purpose |

| `visited` | `set` | Tracks words already processed to avoid cycles. |

## Complexity Analysis

*   **Time Complexity:** $\mathcal{O}(N \cdot L^2)$
    *   Where $N$ is the number of words in `wordList` and $L$ is the length of each word.
    *   Graph construction iterates over $N$ words, creating $L$ patterns of string slicing cost $O(L)$, resulting in $\mathcal{O}(N \cdot L^2)$.
    *   BFS visits each word once and checks $L$ patterns for each word, taking $\mathcal{O}(N \cdot L^2)$ time overall.
*   **Space Complexity:** $\mathcal{O}(N \cdot L^2)$
    *   The `adj` dictionary stores up to $N \cdot L$ patterns, each of length $L$.
    *   The `visited` set and `q` queue store up to $N$ words of length $L$.
